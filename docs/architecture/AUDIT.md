## Consolidation decision and open verification

Keep Compose, existing runner, shared scanner, HTTP client, MCP and CI. Add an installable, independent `barad` adapter without relocating or deleting active modules; a future migration can move shared modules after callers are mapped. Distinguish local **observed** inventory from remotely **published** inventory. Never promote a local cache to proof of remote publication. This stack is loopback HTTP without TLS/SSO and is not production-ready.
